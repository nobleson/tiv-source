# ml

Data pipelines, training scripts, evaluation harnesses, and model cards for the Tiv AI track.

## Goals

- Collect high-quality Tiv speech and text data with proper consent
- Fine-tune open models for ASR, translation, TTS, and the assistant
- Provide clear evaluation sets reviewed by native speakers
- Keep licensing community-governed so the data benefits the Tiv community

This directory is intentionally separated so that universities (including Benue State University) and community contributors can work on language technology without needing deep knowledge of the mobile application.
