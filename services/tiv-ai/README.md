# services/tiv-ai

Self-hosted inference service for:

- Speech-to-text (ASR) in Tiv
- Machine translation (Tiv ↔ English)
- Text-to-speech (TTS) in Tiv
- Conversational assistant (narrow domains in v1)

This is the main place for community and university contributions to the AI track.

See `/ml` for data pipelines, training, and evaluation code.
