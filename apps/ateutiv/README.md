# apps/ateutiv

**ateutiv** — the first product built on the Tiv Source platform.

This package contains:

- Branding and visual identity
- Default community spaces and report categories for Middle Belt / Tiv communities
- Tiv language packs and AI configuration
- Product-specific settings and feature flags

The shared application logic lives in `apps/mobile`.

## Relationship to Tiv Source

Tiv Source is the open platform.  
ateutiv is the first concrete product built from it. Other communities are encouraged to create their own product layers the same way.
